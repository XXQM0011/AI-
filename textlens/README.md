# TextLens

TextLens 是一个本地运行的轻量级文本分析小工具，用于快速查看文本内容、统计词数、提取前 5 个高频词，并将单文件分析或文件夹批量分析结果导出为 Markdown 报告。文件只在本机处理，不需要上传到服务器。

## 解决什么问题

当需要快速了解一批文本的大致内容时，逐个打开文件并手动统计既费时又容易出错。TextLens 提供以下能力：

- 单文件分析：查看文本内容、词数和前 5 个高频词。
- 文件夹批量分析：一次分析文件夹中的所有 `.txt` 文件，并用表格汇总结果。
- 报告导出：将单个文件的分析结果，或整个文件夹的批量分析结果，保存为一个 `.md` 文件。
- 中英混排：英文单词和连续中文都可以参与高频词统计。

## 环境要求

- Python 3.8 或更高版本。
- Python 自带的 tkinter 图形界面库。
- 项目仅使用 Python 标准库，无需安装第三方依赖。

Windows 和 macOS 的官方 Python 通常已包含 tkinter。部分 Linux 发行版可能需要额外安装，例如 Ubuntu/Debian 可安装 `python3-tk`。

## 快速开始

进入项目目录后运行：

```bash
python main.py
```

程序会直接打开 tkinter 图形界面。

## 使用说明

### 单文件分析

1. 点击“选择文件”，选择一个文本文件。
2. 点击“开始分析”，下方会显示文件内容、词数和前 5 个高频词。
3. 点击“导出报告”，选择保存位置，即可生成 `原文件名_分析报告.md`。

### 文件夹批量分析

1. 点击“选择文件夹”。
2. 程序会立即分析所选文件夹当前层的所有 `.txt` 文件，不需要再点击其他分析按钮。
3. 批量结果会以表格显示，包括文件名、词数、前 5 个高频词和读取状态。
4. 点击“导出汇总报告”，即可将全部结果保存到一个 Markdown 文件，默认文件名为 `文件夹名_批量分析报告.md`。

批量报告包含一张汇总表，以及每个成功读取文件的正文、词数和高频词明细；读取失败的文件也会在汇总表中标明状态。

## 支持格式

| 场景 | 支持格式 | 说明 |
| --- | --- | --- |
| 单文件分析 | `.txt`、`.md`、`.csv` | 文件选择框会优先显示这些类型，但实际按纯文本读取，不解析 Markdown 或 CSV 结构。 |
| 文件夹批量分析 | `.txt` | 仅分析所选文件夹当前层的文件，扩展名大小写均可，例如 `.txt` 和 `.TXT`。 |
| 报告导出 | `.md` | 使用 UTF-8 编码保存。 |

所有输入文件都必须使用 UTF-8 编码。

## 统计口径

- 词数与高频词使用同一套正则切词，保证统计口径一致。
- 英文高频词会转为小写后统计，例如 `Hello` 和 `hello` 会合并。
- 英文单词允许包含撇号，例如 `don't`。
- 连续中文会作为一个整体参与统计，不会自动切分成中文词语。
- 单个 ASCII 英文字母会被过滤，例如 `a` 和 `I` 不计入词数或高频词。
- 标点符号和纯数字默认不参与统计。

## 已知限制

- 仅支持 UTF-8 输入，暂不自动识别 GBK、GB18030、Big5 等编码。
- 中文没有接入分词器，连续汉字可能被当作一个词，因此中文词数不是语言学意义上的“词语数量”。
- 高频词统计没有停用词过滤，`the`、`and` 等常见词也可能出现在结果中。
- 高频词只提取前 5 个，暂不支持在界面中调整数量。
- 批量分析只扫描所选文件夹的当前层，不会递归分析子文件夹。
- 单文件选择框中的“所有文件”选项不会改变读取方式，非 UTF-8 或二进制文件可能读取失败。
- 批量报告会包含成功读取文件的完整正文，文件较多或内容较长时会生成较大的 Markdown 文件。
- 中文匹配基于常见汉字范围 `U+4E00` 到 `U+9FA5`，生僻字和部分扩展汉字可能无法被识别为高频词。
